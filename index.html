⚙️ Conexión con el servidor compartido

Esta app ya viene conectada por defecto a la Hoja de Google configurada para la sala de cómputo. Todas las computadoras que abran este mismo archivo verán el mismo inventario en tiempo real. Solo cambia la URL de abajo si tu administrador te indica migrar a un nuevo servidor.

📖 Si necesitas crear un servidor nuevo desde cero
Descarga el archivo google_apps_script_backend.gs.txt que viene junto a esta app.
Entra a sheets.google.com y crea una hoja de cálculo nueva.
En esa hoja, ve a Extensiones → Apps Script, borra el contenido de ejemplo y pega todo el código del archivo .gs.txt.
Guarda el proyecto, luego haz clic en Implementar → Nueva implementación. Tipo: Aplicación web. Ejecutar como: Yo. Acceso: Cualquier usuario.
Autoriza el script cuando Google lo pida. Copia la URL que termina en /exec y pégala arriba.
Inicia sesión con el usuario por defecto admin / admin123 y cámbialo de inmediato desde 👥 Usuarios.
